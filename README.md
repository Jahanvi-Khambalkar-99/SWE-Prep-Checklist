# SWE II Prep Checklist

An interactive, editable study checklist for a 15-week Software Engineer II preparation plan. It covers the pre-start days and Week 1.

## Features

- Tick off timed tasks day by day, with progress shown for each day and overall
- Opens on today's day automatically
- Edit mode: add, edit, reorder and delete tasks, sections and days
- Hide completed tasks
- Progress is saved in your browser (localStorage). Use **Export progress** and **Import progress** to move it between devices.

## Run it

Open `index.html` in any browser, or visit the GitHub Pages site for this repo.
